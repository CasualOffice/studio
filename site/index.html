Some work cannot be uploaded.

An unreleased script. A client brief under NDA. A concept for a pitch you have not won yet. Hosted image tools want all of it on their servers, and for a lot of people that is not a preference to weigh but a contract they would be breaking.

Model Studio runs the same class of open models on your own machine. No account, no API key, no telemetry, no per-image cost. The only network traffic is fetching a model once, which you start.

What it makes is sealed with ChaCha20-Poly1305 before it touches disk, behind a passphrase you choose. Prompts and filenames are encrypted too, so the vault gives nothing away.

Four things, all of them local

Open models, run on your machine, with the memory ceiling worked out for you before you download anything.

Generate

Text to image, with the picture forming step by step as it runs. FLUX.2, Z-Image, Qwen-Image and FLUX.1 all supported.

Edit

Instruction editing, inpainting with a painted mask, outpainting, and reference-guided edits.

Upscale

SeedVR2 restoration. Naive enlargement on the left, the model on the right. About ten seconds for a 2x.

Keep it yours

Everything lands in an encrypted vault. Export a decrypted copy when you want one, and only then. Relocate the whole model library to an external drive without re-downloading.

Write a story. Get a comic.

Paste prose. It is divided into scenes, one character is cast, each room is drawn once, and every panel is set against both so the same person appears in the same place throughout.

Cast the character

Drawn once from your description, or bring a photograph of your own.

Build the room

Each scene gets its own location, drawn empty, so the walls stop changing between frames.

Draw the panels

Every frame references both. Captions and speech are set into the page for you.

A hosted tool

  • Your prompt and your source images sit on someone else's servers
  • Priced per image, forever
  • The model changes under you when they update it
  • A queue between you and the result
  • Terms decide what you are allowed to make

Model Studio

  • Nothing leaves the machine, so NDA work stays inside it
  • Free after the download, with no per-image cost
  • The model is a file you keep, pinned until you change it
  • No queue, and it works with the wifi off
  • Open source under the GPL, so you can read every line
