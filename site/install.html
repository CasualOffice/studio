Install

Three steps, then let it download.

A couple of minutes of setup, then one download you start and leave running.

  1. Download the disk imageand drag Model Studio to Applications.
  2. Clear the quarantine flag, once.macOS calls any app that isn’t signed by a paid Apple Developer account “damaged”. It isn’t damaged; it is unsigned. 
    xattr -dr com.apple.quarantine \
  "/Applications/Model Studio.app"
  3. Open it.The first launch sets up a private Python runtime, then offers the models that make it work, sized for your Mac.
Download for Mac

Budget about 12 GB and twenty minutes before the first picture, almost all of it downloading: roughly 3 GB for the runtime and 9 GB for the starter models. Nothing is installed system-wide, and everything lives in one folder you can delete.

Every model shows its size before you download it, and the app tells you which ones this Mac can actually run before you spend the disk space.

What it needs

Apple Silicon, on purpose.

MLX has no other backend and the key handling is macOS Keychain code, so an Intel or Linux build isn’t a missing target — it is an impossible one.

M1or later. Any Apple Silicon Mac.
macOS 13Ventura or newer.
16 GBto run the catalogue comfortably. 8 GB runs the smaller models.
12 GBof disk to start, more for each model you add.
