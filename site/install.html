Installing

Two minutes of setup, then a download you start once and leave running.

Installing

  1. Download the disk image and drag Model Studio to Applications.
  2. Clear the quarantine flag, once. macOS says any app not signed by a paid Apple Developer account is damaged. It is not damaged, it is unsigned. 
    xattr -dr com.apple.quarantine \
  "/Applications/Model Studio.app"
  3. Open it. First launch sets up a private Python runtime, then offers to install the models that make it work.
Download for Mac

Budget about 12 GB and twenty minutes before the first picture, almost all of it downloading. Roughly 3 GB for the runtime and 9 GB for the starter models. Nothing is installed system-wide, and everything lives in one folder you can delete.

Model sizes are shown before you commit to a download, and the app tells you which models this Mac can actually run before you spend the disk.

What it needs

Apple Silicon only, and that is not an oversight. MLX has no other backend and the key handling is macOS Keychain code, so an Intel or Linux build is not a missing target but an impossible one.
